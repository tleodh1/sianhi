# WORLD 2 해저 탐험 구조

현재 전체 구조는 9 WORLD / 36 STAGE다. 모든 WORLD는 마지막 번호 Stage가 BOSS Stage이며, WORLD 2는 `2-1`~`2-4`, `2-4` 자체가 BOSS다.

| Stage | 구역 | 주요 구성 |
| --- | --- | --- |
| 2-1 | 산호초 | 밝은 얕은 바다, 산호, 물고기 떼, 조개, 기포 기둥 |
| 2-2 | 해초 숲 | 흔들리는 해초, 물살, 높낮이가 다른 모래 지형 |
| 2-3 | 조개 마을 | 진주 조개, 순서 학습, 산호 발판, 숨은 보상 |
| 2-4 BOSS | 심해 수호자의 성 | 난파선 → 유적 → 해구 → 해파리 바다 → 동굴 → 심해 성을 지나 심해왕 루모와 전투 |

## 보존한 해저 시스템

- 원경 절벽, 중경 산호/해초/조개, 플레이 지형, 전경 생물의 다중 Parallax
- 수면광, 깊이별 색 변화, 물안개, 기포 Pool, 수영 Trail
- 고래·가오리·거북·물고기·해파리 장식 생물
- 산호/진주/유적 Block, 기포 상승류, 열리는 조개와 보상
- 복어 팽창, 게 집게, 해파리 부유, 문어 먹물, 상어 돌진, 전기뱀장어 공격과 Telegraph
- 작은 시안 시작, 성장/축소/사망, 글자/별/코인/HP/체크포인트/저장
- 2-4 일반 수영 구간 → 심해 입구 → Scene Transition → Boss Arena → 직접 출구 도착

## 저장 호환

기존 `records.hangulRunner.adventure` 객체를 삭제하거나 다시 쓰지 않는다. `2-4` 완료 기록과 WORLD 2 보상은 그대로 WORLD 3 해금 근거로 사용한다. 잘못 배포됐던 `2-5`~`2-9` 기록이 저장돼 있어도 객체에 남겨 두며, 현재 Registry와 월드맵에는 노출하지 않는다.
