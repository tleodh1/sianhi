## 이전 작업 복구

이전 작업 checkout의 미커밋 `ocean-expedition.js`, `ocean-renderer.js`, `ocean-props.png` 및 연결 변경을 복구했다. 수정 대상 tracked 파일의 이전 HEAD 내용과 기준 main 내용을 바이트 단위 비교해 동일함을 확인했다. 기존 main의 성장/충돌/수집 경로 수정은 유지한다.

`ocean-props.webp`는 기존 생성 원본을 웹 전송용으로 인코딩한 파일이다. 산호, 해초, 조개, 난파선, 유적, 암초, 해파리, 동굴, 에너지 구조물, 고래, 거북, 가오리를 재생성하지 않았다. `marine-hunters.webp`만 상어/전기뱀장어 누락 에셋을 새로 보완했다.

신규 이미지 제작 프롬프트 요약: 투명 배경 2칸 atlas, 우측을 보는 오리지널 청회색 상어와 청록색 전기뱀장어, 귀엽지만 악당 표정, 선명한 실루엣, 고품질 3D toy 질감, 배경/문자/추가 생물 없음. 내장 이미지 생성 사용. 기존 캐릭터 얼굴과 의상 atlas 유지.

기포 56개 재사용 + 고정 개수의 수영/적 기포 + 화면 안 물살 기포. 장식 DOM을 프레임마다 만들지 않는다. 화면 밖 렌더링과 해양 공격 업데이트를 제한한다.

기존 run cycle과 분리한 swim 상태, idle/move/up/down 구분, 느린 paddling 프레임, 몸 기울기와 수영 기포를 연결했다. 신규 얼굴/의상은 만들지 않았다.

12개 학습 구간과 920px 간격을 유지한다. 필수 글자는 상중하로 분산, 긴 문장 타일은 자동 줄바꿈과 확대, 지형/블록 중첩 방지. 하단은 긴 목록 대신 현재 찾을 말과 수집 개수를 표시한다. 대략 5초 간격으로 낱말·적·블록·조개·물살·추가 별·지형 변화가 배치된다.

복어는 접근 후 부풀기, 게는 바닥을 따르며 집게 공격, 해파리는 상하 이동, 문어는 조준 먹물, 상어는 예고 후 돌진, 전기뱀장어는 예고 후 근접 전기 범위 공격을 사용한다.

## 수정 배포 후 확인

`a55ec273314c3acee2678a9f81a8031ebe278396`도 GitHub Vercel status success. 390px Production 검증 화면에서 2-1~2-8 각각 실제 전용 배경과 한글 표시를 확인했고, 수정된 시작 위치의 캐릭터가 산호 위 열린 공간에 표시된다. 2-7의 해파리 단어는 한 줄 표시로 개선됐다. 320/430px에서도 canvas 너비 일치, 가로 콘텐츠 넘침 false, 조작 버튼/게임 영역 중첩 false를 읽었다(1차 배포 기준). 최종 320px 헤더는 짧은 화면에서 조작부 접근성을 높이도록 압축했다.

Cloud Chrome에서 관찰한 짧은 샘플의 평균 canvas 그리기는 약 1~2ms/프레임이었으나, 이는 실기기 FPS 또는 iPhone 성능 보장이 아니다. 실제 iPhone Safari·동시 멀티터치·장시간 플레이 및 운영본 보스전 전 과정은 미검증. 보스 전 과정은 자동 시뮬레이션으로 검증했다.
