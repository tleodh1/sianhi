# 시안Hi 홈 개편 · 동작 안정화

## 배포 범위

- 기존 `tleodh1/sianhi` main을 유지. 별도 Adventure 사이트는 삭제하거나 변경하지 않음.
- 하늘 성·떠 있는 섬 배경, 사용자 제공 시안이 사진, 프리텐다드 자체 호스팅.
- 홈 / 게임 / 학습 / 기록 / 수집 / 보호자 화면과 모든 메뉴 연결.
- 기존 6개 게임과 8과목 지도 보존. DOM 기반 게임이며 전체 3D 구현이 아님.
- 기존 `sianhi-v2`의 별, 완료 목록, 과목 진도를 읽음. `팩토` 진도는 `사고력 수학`으로 호환.
- 저장 JSON 오류가 있어도 시작 가능. 저장 실패 알림, JSON 내보내기/가져오기.
- 게임 닫기·전환 시 타이머, 반복 루프, 키보드 리스너 해제.
- 첫 연산은 10 이내 덧셈/뺄셈, 한글은 가~하 낱말, 영어는 대소문자부터 시작.
- 코딩 첫 단계에서 목표까지 갈 수 없던 명령 개수 제한 수정.
- 학습 미션 반복에 따른 중복 별 지급 방지. 정답 후 사용자가 다음 미션 선택.

## 미완성 범위 — 완료로 표시하지 말 것

- 참고 이미지 수준의 실제 3D 캐릭터/플랫폼 물리/적 AI.
- 로봇 조립·실시간 아레나와 부품별 컬러·능력치·격납고.
- 실제 명화 직소 퍼즐, 3D 인형뽑기, 몬스터 도감.
- 모든 과목 100개의 독립적인 완성형 콘텐츠: 현재 지도는 100단계지만 후반 문제는 기존 반복 템플릿.
- 완성된 스토리텔링 영상. 현재는 문장과 브라우저 음성 읽기.
- 다른 도메인/기기 진도 자동 병합 및 서버 계정 동기화.

## 유지보수

- `index.html`: 문서와 전역 메뉴/게임 다이얼로그.
- `css/home.css`: 새 홈·반응형 화면. `css/style.css`: 기존 게임 스타일.
- `js/core.js`: 로컬 저장과 Session 생명주기.
- `js/app.js`: 화면 렌더와 사용자 액션.
- `js/learning.js`: 커리큘럼/문제/지도/코딩.
- `js/games.js`: 기존 6개 게임. 새 게임 개발 시 독립 모듈로 분리할 것.
- `npm run dev`: 개발 서버. `npm test`: 구문, 단계 정답, 코딩 명령 예산, 자산 검사.

## 자산 출처

`sian-face.webp`는 사용자가 홈페이지 상단 배치를 요청한 사진을 크기 최적화하고 메타데이터 없이 저장한 파일.
`sky-world.webp`는 내장 이미지 생성 도구로 제작한 시안Hi 전용 배경.
프롬프트: 밝은 파란 하늘, 부드러운 구름, 파스텔 지붕의 성과 폭포가 있는 떠 있는 섬, 둥근 나무와 나무다리. 장난감 3D 스타일, 글자·UI·로고·인물 없음.
