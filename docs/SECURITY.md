# Security

## 현재 보안 범위

현재 시안Hi는 정적 프론트엔드 앱이며 진도는 localStorage에 저장됩니다. 서버 로그인·결제·관리자 API가 없기 때문에 서버형 서비스보다 공격 표면은 작지만, 공개 웹사이트이므로 기본 웹 보안은 적용합니다.

## 저장소 점검

2026-09-18 기준 저장소 코드 검색에서 `api_key`, `apikey`, `service_role`, `supabase`, `password`, `secret`, `token` 문자열에 해당하는 커밋된 자격증명은 확인되지 않았습니다. 검색 결과만으로 과거 커밋 전체의 비밀정보 부재를 보증할 수는 없습니다.

## 필수 규칙

- Service Role Key, private API key, 관리자 비밀번호를 브라우저 JS에 넣지 않습니다.
- `.env*`는 Git에 커밋하지 않습니다.
- 공개 브라우저에서 사용할 수 있는 값과 서버 전용 비밀값을 구분합니다.
- 향후 Supabase 사용 시 모든 사용자 데이터 테이블에 RLS를 켜고 정책을 먼저 작성합니다.
- 관리자/부모 인증을 단순 JS 문자열 비교로 구현하지 않습니다.
- 외부 입력/URL parameter/DB 값을 `innerHTML`에 직접 삽입하지 않습니다.
- 파일 업로드 추가 시 MIME, 확장자, 크기, 저장 경로를 서버에서 검증합니다.
- 실제 아이 사진의 원본 EXIF/불필요한 메타데이터를 공개 배포하지 않습니다. 게임용 최종 에셋만 배포합니다.
- 오류 화면에 내부 키/환경변수/stack trace를 노출하지 않습니다.

## 배포 헤더

`vercel.json`에서 클릭재킹 방지, MIME sniffing 방지, referrer 제한, 브라우저 기능 제한, HTTPS HSTS 및 기본 CSP를 적용합니다.

현재 레거시 코드에는 inline style/handler 패턴이 일부 있으므로 CSP는 호환성을 위해 `unsafe-inline`을 일부 허용합니다. 리팩터링 후 inline handler/style을 제거하면 CSP도 더 엄격하게 강화해야 합니다.

## 개인정보

시안Hi가 공개 사이트인 경우 실제 아동의 원본 사진, 생년월일, 학교/유치원, 위치, 연락처 같은 개인정보를 화면·소스·파일명·EXIF에 넣지 않는 것을 원칙으로 합니다.
