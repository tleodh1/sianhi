Success/retry scripts rotate. Speech requests cancel earlier requests and release ducking on completion/error/cancel.

No recorded/neural voice assets are installed. Native voices remain the fallback; expressive consistent voice identity cannot be claimed. Optional offline builder exists but no API key/service was available and no paid calls were made. See assets/audio/NOTICE.md.
