# 시안Hi

누리과정부터 초등 저학년까지 게임으로 학습하는 어린이용 웹 프로젝트입니다.

## 운영 구조

- `index.html` — 앱 진입점과 공통 레이아웃
- `css/style.css` — 현재 레거시 통합 스타일. 새 기능은 영역별 파일 분리를 원칙으로 합니다.
- `css/home.css` — 하늘 모험 홈과 반응형 페이지
- `js/app.js` — 홈·메뉴·기록·보호자 화면
- `js/core.js` — 저장 호환과 게임 생명주기
- `js/learning.js` — 커리큘럼·단계 지도·코딩 활동
- `js/games.js` — 기존 6개 게임
- `assets/` — 이미지/게임 에셋
- `docs/ARCHITECTURE.md` — 구조와 유지보수 원칙
- `docs/SECURITY.md` — 보안 기준
- `docs/DEPLOYMENT.md` — 배포/인수인계 절차
- `vercel.json` — 배포 보안 헤더

`npm run dev`로 로컬 서버를 실행하고 `npm test`로 기본 검사를 실행합니다.
이번 반영 범위와 미완성 기능은 `docs/RELEASE-2026-09-18.md`에 구분했습니다.
현재는 전체 3D 플랫폼 완성본이 아니며, 후반 학습 문제에는 반복 템플릿이 포함되어 있습니다.

## 학습 영역

연산 · 수학 · 사고력 수학 · 한글 · 영어 · 과학 · 코딩 · 한자 · 게임월드

사고력 수학은 시각적 수 감각·규칙·논리·공간·도형·조건 추론 중심의 독자 문제를 사용합니다. 특정 문제집의 문제/그림을 복제하지 않습니다.

## 데이터

현재 학습 진도는 브라우저 `localStorage`의 `sianhi-v2` 키에 저장됩니다. 서버 계정/DB가 없으므로 브라우저나 기기를 바꾸면 자동 동기화되지 않습니다.

## 개발 원칙

1. 기능 하나를 수정할 때 다른 게임을 깨뜨리지 않습니다.
2. 새 비밀키/API 키/관리자 비밀번호를 프론트엔드 코드나 Git에 넣지 않습니다.
3. 새 게임은 독립 모듈과 독립 스타일 파일로 분리합니다.
4. 사용자 입력은 가능한 `textContent`로 렌더링하며, 신뢰하지 않는 값을 `innerHTML`에 삽입하지 않습니다.
5. 배포 전 홈·학습·기록·게임월드의 전체 회귀 테스트를 수행합니다.

자세한 인수인계 내용은 `docs/`를 확인하세요.
